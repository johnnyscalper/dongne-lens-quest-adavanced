# 자료 출처와 계산 기준

## 자료 모드

| 모드 | 출처 | 의미 |
| --- | --- | --- |
| 서버 가상 예시 | `demo.py` | 재현 가능한 가상 단지·금액. 날짜만 현재 KST 조회기간에 맞춘 체험 자료. 실제 시세가 아님 |
| 설치 없는 가상 예시 | `public/local-api.js` | 브라우저에서 생성하는 체험 자료. 인터넷 없이 작동하며 실제 시세가 아님 |
| 공식 실거래 | 국토교통부 아파트 매매·전월세 API | 신고된 계약 자료. 현재 매물 호가·감정평가·공식 가격지수가 아님 |

가상 자료는 지역별 실제 가격을 추정한 값이 아니다. 공식 조회가 실패할 때 가상 모드로 자동 전환하지 않는다. 코드·문서·테스트 응답을 검토했지만 **인증키를 사용한 실서비스 응답 검증은 아직 하지 않았다.**

Python과 브라우저 가상 생성기는 서로 다른 재현 가능한 값을 만들 수 있다. 같은 거래 배열에 대한 계산·실험 결과는 런타임 비교 테스트로 관리한다. 설치 없는 파일·비공개 정적 웹앱에서는 공식 자료를 조회하지 않는다.

| 구분 | endpoint |
| --- | --- |
| 매매 | `https://apis.data.go.kr/1613000/RTMSDataSvcAptTrade/getRTMSDataSvcAptTrade` |
| 전월세 | `https://apis.data.go.kr/1613000/RTMSDataSvcAptRent/getRTMSDataSvcAptRent` |

서버만 `serviceKey`, `LAWD_CD`, `DEAL_YMD`, `pageNo`, `numOfRows`를 전송한다. `MOLIT_SERVICE_KEY`의 실제 값은 응답·브라우저·로그에 포함하지 않는다.

## 정규화와 조회 범위

- 국토부 금액 필드의 **만원**을 내부 **원**으로 변환한다. 예: `12,000`만원 → `120,000,000`원.
- `dealAmount`는 매매금액, `deposit`은 임대보증금, `monthlyRent`는 월세다. `monthlyRent`가 0이면 전세, 0보다 크면 월세로 분류한다.
- `excluUseAr`는 전용면적㎡, `aptNm`은 단지명, `umdNm`은 법정동, `dealYear/dealMonth/dealDay`는 계약일이다.
- 현재 KST 월을 포함한 3·6·12개월을 조회한다. 진행 중인 달은 아직 완료되지 않은 기간이며, 오늘 이후 계약일은 제외한다.
- `totalCount`를 기준으로 페이지를 읽는다. 조회당 한 종류·한 월 최대 5페이지, 화면 분석 최대 5,000건을 적용한다. 한도·오류·결측으로 일부 자료가 빠지면 불완전 상태와 이유를 표시한다.
- 정상화할 수 없는 필수 값은 제외하고 건수를 알린다. 알 수 없는 금액을 0으로 채우지 않는다. 동일한 금액·면적의 거래가 여러 건일 수 있으므로 값이 같다는 이유만으로 삭제하지 않는다.
- 매매의 해제 표시·해제일을 읽어 해제 거래를 통계에서 제외한다. 반환된 자료에 없는 해제·정정 상태를 추정하지 않는다.
- 완전한 조회 결과는 최대 15분 동안 메모리에 캐시한다. 불완전 결과는 캐시하지 않는다. 서버 재시작 시 캐시는 사라진다.

자료는 계약일 기준이며 신고·정정·해제로 이전 기간도 달라질 수 있다. 앱은 조회할 때 선택 기간 전체를 다시 요청하며, 장기 원본 이력이나 공식 통계를 별도로 구축하지 않는다. 호출 한도·접근 승인은 공공데이터포털의 현재 안내를 따른다.

## 집계와 조건 적합도

모든 값은 선택한 지역·동·면적·기간 안에서 계산한다. 매매·전세·월세는 별도 표본의 중위값이다. 월세는 보증금 조건이 섞여 있으므로 월세 중위값만으로 임대조건이 같다고 볼 수 없다.

| 지표 | 계산 |
| --- | --- |
| 예산 이하 거래 비율 | 예산 이하 매매 건수 ÷ 유효 매매 건수 |
| 예산 적합 점수 | `60 × min(1, 예산 ÷ 매매 중위값)` |
| 자기자금 여력 점수 | `40 × min(1, 자기자금 ÷ 매매 중위값)` |
| 총 조건 적합도 | 두 점수의 합. 매매 5건 미만이면 표시하지 않음 |
| 표본 상태 | 매매 5건 미만: 부족 / 5~19건: 제한적 / 20건 이상: 충분 |

점수와 표본 상태는 가격상승·미래 수익·원본 정확도·개인별 상환 능력의 신뢰도를 뜻하지 않는다. 예산 이하 비율도 현재 구매할 수 있는 매물 비율이 아니다.

월별 중위값은 거래된 단지·면적·층의 구성 변화에 영향을 받는다. 단지 표는 같은 단지명·법정동을 묶으며, 서로 다른 면적·층의 거래가 포함될 수 있다. 매매 표본이 많은 상위 30개 단지를 표시한다.

## 가격 착시 탐정

선택 기간을 달 단위의 앞·뒤 두 구간으로 나눈다. 홀수 개월이면 뒤 구간이 한 달 더 길고, 조회 마지막 달은 진행 중일 수 있다. 날짜 범위·표본 수·매칭 비중을 함께 읽는다.

| 항목 | 계산·조건 |
| --- | --- |
| 전체 변화율 | `(뒤 구간 전체 매매 중앙값 / 앞 구간 전체 매매 중앙값 − 1) × 100` |
| 매칭 그룹 | 동일 지역 코드·법정동·단지명·5㎡ 면적 구간. 구간 하한 포함, 상한 제외 |
| 최소 표본 | 전후 각각 2건 이상인 매칭 그룹이 2개 이상 필요 |
| 동일 구성 변화율 | `(Σ(앞 건수 × 뒤 그룹 중앙값) / Σ(앞 건수 × 앞 그룹 중앙값) − 1) × 100` |
| 매칭 비중 | 각 구간 매칭에 사용한 거래 건수 / 해당 구간 전체 유효 매매 건수 |
| 표본 부족 | 동일 구성 변화율을 `null`로 반환. 0%로 채우지 않음 |

앞 구간 거래 건수를 고정 가중치로 사용한다. 같은 세대의 반복 거래가 아니며 층·향·수리·정확한 면적 차이 등을 보정하지 않는다. 전체와 매칭 비교는 모집단과 집계 방식도 다르므로 **두 변화율의 차이를 구성 변화가 일으킨 상승분으로 해석할 수 없다.**

착시 연습 예제는 작은집 5억·넓은집 10억이라는 가격을 유지한 채 거래 건수를 8:2에서 2:8로 바꾼 가상 자료다. 전체 중앙값 변화는 +100%, 동일 구성 비교는 0%가 된다. 예제의 집·날짜·가격은 선택 지역의 실제 시세와 무관하다.

## 주소 블라인드 선택실험

매매 2건 이상인 같은 지역·동·단지·5㎡ 구간을 후보로 만든다. 후보가 2개 이상이어야 실행한다. 후보가 3개 이상이면 매매 중앙값이 낮은·중간·높은 그룹을 하나씩 고른 뒤 고정된 익명 카드 순서로 표시한다. 지역 전체를 대표하는 무작위 표본이 아니다.

카드의 면적·가격·㎡당 가격은 해당 그룹의 중앙값이고 표본 수·계약 기간을 함께 제공한다. 현재 매물이나 특정 한 세대를 뜻하지 않는다. 이름 공개 후 선택을 유지하거나 바꾸는 경험이며 정답·성향 진단·투자 추천은 없다. 주소 숨김은 화면 연출로, 보안상 익명화가 아니다. 선택 결과는 저장하지 않는다.

## 자금 시나리오

| 항목 | 가정 |
| --- | --- |
| 필요 대출 | `max(매매 중위값 − 자기자금, 0)` |
| 월 원리금 | 필요 대출을 기본 30년 원리금균등상환으로 계산. 0% 금리도 처리 |
| 금리 충격 | 입력 금리에 **2%p**를 더해 같은 대출·기간의 월 원리금을 다시 계산 |
| 월 임대 현금흐름 | `월세 중위값 × (1 − 공실률 5%) − 월 이자 − 연 운영비 240만원 ÷ 12` |
| 보증금 반환 차액 | 전세 중위값의 **10%**. 다음 보증금이 10% 낮아진다는 가정 |

월 현금흐름에는 원금상환·세금이 포함되지 않는다. 취득세·중개보수·등기비용·대규모 수선비·보유세도 별도 검토 대상이다. 소득·기존 부채·대출 규제를 입력받지 않아 대출 가능액이나 승인 여부를 판정하지 않는다.

전월세 자료는 동·호 정보가 없어 매매자료와 동일 세대로 단정할 수 없다. 앱은 지역 대표값으로 상황을 비교하며, 임대보증금을 수익으로 계산하거나 매입 대출에서 차감하지 않는다.

## 저장과 공유

서버는 사용자별 분석 이력을 저장하지 않는다. 체험 프로필은 실제 회원 인증이 아니며 비밀번호·연락처·결제 정보를 받지 않는다. 닉네임·최근 검색·관심집은 해당 브라우저에만 보관하고 내정보에서 삭제할 수 있다. 프로필 이름을 바꾸어도 서로 다른 보안 계정이 만들어지는 것은 아니다.

관심집에는 저장 시점의 단지 집계·조회 기간·가상/공식 모드가 포함된다. 현재 매물이나 계속 갱신되는 시세가 아니다. 금융 입력과 블라인드 선택 이력은 자동으로 영구 보관하지 않는다. 사용자가 내려받는 JSON에는 자금 가정과 출처·필터·결과가 포함되며 지역 링크 공유에는 예산·자기자금·금리를 넣지 않는다.

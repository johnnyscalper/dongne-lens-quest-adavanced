# Adavanced · 10개 에이전트 검토

v0.5는 기존 실행·계산 기반을 유지하면서 모바일 탐색과 화면 전환, 체험 프로필·관심집을 보강하는 작업입니다. 역할별 구현과 독립 검토를 나누고 통합 담당이 실제 실행·배포 결과를 확인합니다.

| 번호 | 담당 | 범위 |
| --- | --- | --- |
| 1 | 제품·공식 참고 자료 | KB 공식 자료의 검색·단지·관심집 동선을 검토하고 독자 화면 구조 제안 |
| 2 | GitHub·브라우저 | Private 저장소 실제 반영, 브라우저 동작·반응형 확인 |
| 3 | 모바일 화면·스타일 | 체험 시작, 여섯 화면, 하단 탭, 검색·상세 패널과 터치 레이아웃 |
| 4 | 화면 흐름·기기 내 기록 | 라우팅·뒤로가기·체험 프로필·최근 검색·관심집·포커스 |
| 5 | 거래 클라이언트 | 검색 성공 이벤트·거래유형 카드·집계·기존 API 연결·오래된 응답 차단 |
| 6 | 3D·움직임 | 화면 재배치·비활성 중지·사용자 일시정지·작은 화면 조작 |
| 7 | 자동 검사 | 모바일 저장 검증·오류 처리·화면과 빌드 계약 회귀 검사 |
| 8 | 실행·문서 | 모바일·Replit·설치 없는 파일·인증과 자료 한계·실제 검증 상태 안내 |
| 9 | 보안·정확성 | 저장·동적 텍스트·모드 분리·오해 가능한 인증·금융 표현 검토 |
| 10 | 독립 최종 검토 | 통합 동작·소스·생성물·실행 경로·최종 전달 범위 검토 |

에이전트의 구현 완료만으로 원격 반영이나 배포 성공을 뜻하지 않습니다. 실제 결과는 [검증 기록](VALIDATION.md)을 따릅니다.

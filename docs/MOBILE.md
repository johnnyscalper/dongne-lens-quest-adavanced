# 모바일 사용과 화면 구성

동네렌즈 퀘스트 (Adavanced) v0.5는 휴대폰 브라우저에서 여는 **모바일 웹앱**입니다. Android·iPhone용 스토어 설치 파일을 제공하는 네이티브 앱은 아닙니다. 비공개 웹 주소와 Replit 서버는 같은 화면 코드를 사용하고, `play.html`은 가상 자료 체험을 한 파일로 제공합니다.

## 한 번의 탐색

1. 첫 화면에서 닉네임으로 **체험 프로필**을 시작하거나 게스트로 둘러봅니다.
2. 홈에서 지역을 검색합니다. 지원하는 구·동을 선택하면 거래 화면으로 이동합니다.
3. 매매·전세·월세와 기간·면적 조건을 바꿔 단지별 거래 집계를 봅니다.
4. 단지를 눌러 상세 패널을 열고 관심집으로 저장합니다.
5. 자금 계획 화면에서 예산·자기자금·금리를 입력합니다. 이 계산은 **지역의 매매 중앙값 기준**이며 선택한 단지의 매수 견적이 아닙니다.

하단의 홈·탐색·실험·관심·내정보 탭으로 이동합니다. 검색 결과에서 뒤로 돌아가거나 상세 패널을 닫을 때 기존 조회 조건을 유지합니다. 가격 착시 탐정과 주소 블라인드 선택실험은 실험 화면에 있습니다.

## 프로필과 관심집

- 체험 프로필은 실제 회원 인증이 아닙니다. 비밀번호·인증번호·소셜 계정 정보를 받지 않습니다.
- 닉네임·최근 검색·관심집은 해당 브라우저에만 보관합니다. 다른 기기로 자동 동기화하지 않습니다.
- 최근 검색은 6개, 관심집은 24개까지 보관합니다. 체험을 종료해도 관심집은 유지하며, 내정보의 기록 지우기로 삭제할 수 있습니다.
- 관심집은 저장 시점의 거래 집계입니다. 현재 매물·현재 시세가 아니며 가상/공식 모드와 조회 기간을 구분합니다.
- 금융 입력은 자동으로 영구 보관하지 않습니다. 사용자가 내려받는 분석 JSON에는 계산 가정이 포함됩니다.
- 브라우저가 저장을 허용하지 않아도 현재 화면에서 체험할 수 있습니다. 내정보에서 기기 내 기록을 지울 수 있습니다.
- 비공개 Sites의 소유자 접근 제어와 앱 안의 체험 프로필은 서로 별개입니다.

## 화면 설계

긴 대시보드를 여섯 화면으로 나누고, 검색·단지 상세에는 대화상자를 사용합니다. 터치 조작 영역, 휴대폰 안전 영역, 키보드 포커스와 뒤로가기를 고려했습니다. 움직임 감소 설정에서는 화면 전환 효과를 줄이고 3D 장면을 정지 상태로 시작합니다. 실제 확인한 화면 크기와 검사 범위는 [검증 기록](VALIDATION.md)을 참고하세요.

KB부동산의 공식 안내에서 **지역 검색 → 단지 정보 → 거래유형·가격 흐름 → 관심집**이라는 정보 구조를 참고했습니다. 동네렌즈의 브랜드·화면·그래픽과 코드로 새로 구성했으며 KB의 로고·시세 데이터·회원 시스템을 사용하지 않습니다.

- [KB 공식 시세 조회 안내](https://kbthink.com/house/kb-prices.html)
- [KB국민은행의 Google Play 앱 소개](https://play.google.com/store/apps/details?id=com.kbstar.land&hl=ko)

위 자료의 기능 설명을 참고한 것이며, KB 앱의 애니메이션 시간이나 내부 구현을 측정·복제한 것은 아닙니다.

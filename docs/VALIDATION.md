# Adavanced v0.5 검증 기록

## 2026-11-03 · 행사 제출 최종 검수

- 화면 브랜드·탭 제목을 동네렌즈 퀘스트로 통일. 저장소 이름/주소 유지.
- 모바일 검색 시트의 높이를 visualViewport에 맞추고 검색 입력/버튼을 고정. 입력 중 하단 메뉴 숨김, 포커스 스크롤 여백, 가격 카드/버튼/입력 글꼴 정리.
- 자동 95개 테스트, JS 문법, 정적 생성물 일치, diff 공백 검사 통과.
- 실제 Chromium 1280×900, 390×844, 320×640에서 게스트→마포구 조회→결과→블라인드 선택/공개/최종 선택→가격 가정→결과 확인. 가로 넘침·앱 콘솔 오류 없음.
- B 기준 1,641,500,000원에서 15% 가정 할인 시 1,395,275,000원, 차액 246,225,000원 확인.
- 조절/확정 전후 market.records 216건의 내용, analysis, assumptions, filters, localStorage 동일 확인. 자금계획 monthly_payment 2,406,755원 유지.
- 기간 6→12개월 변경 시 432건 조회, 블라인드 1단계로 초기화 및 이전 가격 결과 제거 확인.
- 390×500 키보드 축소 화면 시뮬레이션에서 검색 입력/실행 버튼 접근 가능. 320px에서 세 확정 버튼을 하단 메뉴 위로 스크롤하여 실행 확인.
- 별도 비로그인 Chromium과 인증 정보 없는 HTTP 요청 모두 Preview 200. Replit 로그인·워크스페이스 권한 요구 화면 없음. 개발 서버 생존 기간과 향후 접근 정책, 심사자 실제 기기/네트워크 접근은 보장하지 않음.
- 실기기 키보드·Safari·공식 API·정적 실행본 별도 브라우저 전체 흐름은 미확인. 이번 요청에서는 배포하지 않음.

## 2026-11-03 · 내 선택의 가격 (로컬 Preview)

- 작업 브랜치: `feat/choice-price`. 기존 Python 서버와 개발 Preview 재사용. 원격 게시·PR·배포 없음.
- `python3 -m unittest discover -s tests -v`: 95개 통과, 건너뜀 없음.
- 신규 모델 검사: 0~30% 모든 정수 할인율·원 단위 반올림·차액, 잘못된 값 거부, 동결된 원본 후보 보존, 조절만으로 미확정, 세 가지 명시적 확정, 후보/전체 초기화.
- `npm run check:js`, `python3 build_static.py --check`, `git diff --check` 통과. `play.html`과 무시 대상 `dist/index.html` 재생성.
- 실제 Chromium Preview: 게스트·지역 검색 → 발견 → 블라인드 선택 → 공개 후 유지/변경 → 가격 실험 진입/건너뛰기 → B 선택 → 0/10/30%·+/− → B/A/판단 어려움 확정 → 세 단계 결과 → 복사 확인.
- 데스크톱 및 390px·320px에서 전체 흐름 확인. 원 단위 금액 가로 잘림 없음, 주요 조작 48px. 고정 내비게이션 뒤로 지나가는 중간 콘텐츠는 스크롤로 도달하며 마지막 콘텐츠도 내비게이션 위로 올라옴.
- 후보 변경·다시 해보기·블라인드 재시작·지역 변경·6→3개월 변경 시 초기화 확인. 취소 뒤 남던 스크린리더 확정 안내를 수정한 뒤 재검증 통과.
- 클립보드 정상 복사 확인. 브라우저 API 거부를 임시 시뮬레이션했을 때 직접 선택 가능한 읽기 전용 텍스트와 수동 복사 안내 확인.
- 0→30→7→19→10 DOM input 이벤트 연속 입력 직후 및 200ms 후 727,000,000원 기준 654,300,000원으로 일치, 미확정 유지. 신뢰된 실제 손가락 이벤트 연속 입력 검사는 아님.
- 모션 감소를 `matchMedia`로 임시 시뮬레이션: 가격 숫자 animate 호출 0회. 검사 후 원상복구. 실제 모바일 기기의 OS 모션 감소 설정은 확인하지 않음.
- 확인한 콘솔에 앱 오류 없음. 공식 API·실제 모바일 기기·다른 브라우저 및 정적 실행본의 별도 브라우저 전체 흐름은 이번 확인 범위 밖.

## 이번 변경에서 확인할 동작

- 초기 자료 조회가 체험 시작 화면을 건너뛰지 않음.
- 명시적인 검색 성공 후에만 거래 화면으로 이동하며 자금 입력 중 화면이 바뀌지 않음.
- 실패한 검색에서 이전 결과를 지우고 검색 패널에 오류 표시.
- 매매·전세·월세 카드가 선택 조건의 거래 집계와 일치.
- 관심집에 가상/공식 모드와 저장 시점·조회 기간을 유지.
- 숨김 화면에서 3D 렌더링을 멈추고 재진입 시 크기·사용자의 일시정지 상태를 보존.
- 44px 조작 영역, 키보드 포커스, 뒤로가기, 움직임 감소 설정 확인.

## 확인 범위의 한계

- 가상 자료는 실제 시세가 아니며 Python과 브라우저의 예시 금액은 다를 수 있습니다. 동일한 거래 입력의 계산 결과를 비교합니다.
- 실제 발급키를 이용한 국토부 응답·Replit 게시 환경의 외부 API 연결은 별도 확인이 필요합니다.
- 실제 모바일 기기·다양한 브라우저·장기 운영·대규모 동시접속은 별도 검증 범위입니다.
- 체험 프로필은 인증·권한 분리·다중 기기 동기화를 제공하지 않습니다. 저장 데이터는 같은 브라우저 안의 체험 기록입니다.
- GitHub Private 저장소와 비공개 웹앱의 접근 권한은 별개이며 실제 원격 상태 확인을 기준으로 합니다.

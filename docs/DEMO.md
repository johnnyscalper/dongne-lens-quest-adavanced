# Adavanced v0.5 · 60초 시연 — 손안에서 다음 집으로

휴대폰에서는 비공개 웹앱을, 컴퓨터에서는 `play.html` 또는 웹앱을 엽니다. Replit 서버도 같은 화면 흐름을 제공합니다. 가상 예시 모드·최근 6개월·전체 면적을 사용합니다. 이 시연의 단지와 가격은 실제 시장자료가 아닙니다.

| 시간 | 조작 | 말할 내용 |
| --- | --- | --- |
| 0–10초 | 3D 시작 화면에서 체험 프로필 또는 게스트 진입 | “내가 살 동네를 찾아가는 모바일 웹앱입니다. 회원정보 없이 가상 자료로 먼저 체험합니다.” |
| 10–25초 | 성동구 검색 → 거래 화면 이동 → 전세/월세 전환 | “지역을 고르면 거래를 바로 살펴보고, 같은 조회 조건에서 거래유형을 바꿉니다. 가격과 함께 표본 수를 보여줍니다.” |
| 25–35초 | 단지 상세 열기 → 관심 저장 → 관심 탭 | “마음에 든 단지의 거래 집계를 이 브라우저에 남깁니다. 현재 매물이 아니라 저장 시점의 자료입니다.” |
| 35–50초 | 실험 탭에서 가격 착시 연습 예제와 블라인드 선택 | “집값이 같아도 거래 구성이 달라지면 전체 중앙값은 달라집니다. 이름을 가리고 고른 집도 확인하며 내 기준을 발견합니다.” |
| 50–60초 | 자금 계획에서 금리 변경 | “지역 매매 중앙값을 기준으로 내 예산과 매달 부담을 살펴봅니다. 숫자를 입력하는 동안 화면이 갑자기 바뀌지 않습니다.” |

## 시연에서 지킬 표현

- 3D 마을은 실제 지역 지도나 특정 단지를 복원한 장면이 아닙니다. 재생·일시정지, 처음부터, 타임라인 조작으로 직접 장면을 보여줍니다.
- 움직임 감소 설정이 켜져 있으면 정지 상태로 시작합니다. 필요한 경우 재생 버튼을 눌러 시연합니다.
- 실제 지역 데이터와 연습 예제를 구분합니다. 연습 예제의 100%는 선택 지역의 가격 변동이 아닙니다.
- 같은 구성 비교도 층·향·상태가 다른 거래를 포함합니다. 공식 가격지수나 상승 원인 판정이라고 설명하지 않습니다.
- 블라인드 카드는 과거 표본의 집계이며 현재 매물이 아닙니다. 이름 공개 후의 선택은 성향 진단이나 투자 등급으로 점수화하지 않습니다.
- 착시 연습 예제에서는 작은집 5억·넓은집 10억이 유지됩니다. 넓은집 거래 비중만 커져 전체 중앙값은 +100%, 같은 구성 비교는 0%입니다.
- 체험 프로필을 실제 인증이나 계정별 보안 저장으로 설명하지 않습니다. 금융 입력은 자동 영구 저장하지 않습니다.
- 차별점은 **손안의 입체 탐험 + 해석을 바꾸는 체험 + 근거 공개**입니다. 다른 서비스에 전혀 없는 기능이나 수상을 보장한다고 주장하지 않습니다.

## 표본이 부족할 때

기간을 12개월로 넓히거나 동·면적 조건을 해제합니다. 그래도 비교 가능한 그룹이 없으면 부족 상태를 그대로 보여주고 착시 연습 예제를 사용합니다. 빈 결과에 숫자를 채워 시연하지 않습니다.

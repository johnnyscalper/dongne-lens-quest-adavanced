# 동네렌즈 퀘스트 (Adavanced)

**다음 집으로 가는, 나만의 궤도. · v0.5.0**

휴대폰에서 **체험 시작 → 지역 검색 → 거래 보기 → 단지 상세 → 관심집 저장**으로 이어지는 가벼운 부동산 웹앱입니다. 블랙·아이보리·민트 화면, 움직이는 3D 마을, 하단 탭으로 서울 25개 구의 거래와 내 조건을 살펴봅니다. 외부 프런트엔드 라이브러리·유료 AI·데이터베이스가 필요 없습니다.

> 기본 체험의 단지명·가격·거래는 **가상 예시**입니다. 현재 시세나 현재 매물이 아닙니다. 공식 실거래 조회는 Python 서버에서 API 키를 설정해야 합니다.

## 바로 실행하는 세 가지 방법

| 방법 | 시작 | 제공 범위 |
| --- | --- | --- |
| **설치 없이 체험** | 저장소를 다운로드·압축 해제한 뒤 **[play.html](play.html)**을 브라우저로 열기 | 인터넷 연결·Python 없이 모바일 UI, 검색, 관심집, 두 실험, 자금 계산 |
| **Python / Replit** | `python3 server.py --host 0.0.0.0 --port 3000` | 가상 자료 + 선택적인 국토부 공식 자료 연결 |
| **비공개 웹앱** | [동네렌즈 퀘스트 (Adavanced) 열기](https://dongne-lens-adavanced-johnny.johnjeongv12.chatgpt.site) | 설치 없는 가상 자료 체험, 소유자만 접근. 배포 확인 상태는 [검증 기록](docs/VALIDATION.md) 참고 |

GitHub의 파일 보기 화면은 앱을 실행하지 않습니다. `play.html`을 **내 컴퓨터에 내려받아 열거나** 위 웹앱을 사용하세요. 로컬 파일의 화면 링크는 다른 사람에게 전달해도 열리지 않으므로 파일 경로를 복사하지 않습니다.

**휴대폰에서는 위 비공개 웹앱 주소를 브라우저로 여는 방법을 권합니다.** 앱스토어 설치 파일이 아닌 모바일 웹앱입니다. 첫 화면에서 닉네임으로 체험 프로필을 만들거나 게스트로 시작합니다. 실제 회원 인증·비밀번호 입력은 없습니다. [모바일 사용 안내](docs/MOBILE.md)

Windows에서는 `start.bat`, macOS/Linux에서는 `sh start.sh`로 서버를 시작할 수 있습니다. Python 3.11 이상이 필요하며 실행 후 [http://localhost:3000](http://localhost:3000)을 엽니다. 실행 스크립트는 패키지를 설치하지 않습니다.

**Replit:** 새 비공개 저장소 [johnnyscalper/dongne-lens-quest-adavanced](https://github.com/johnnyscalper/dongne-lens-quest-adavanced)에 접근할 수 있는 계정으로 가져오고 **Run**을 누릅니다. `.replit`에 서버 명령과 포트가 들어 있습니다. [자세한 실행 안내](docs/REPLIT.md)

## 핵심 체험

| 체험 | 동작 |
| --- | --- |
| **모바일 탐색** | 홈·탐색·실험·관심·내정보 하단 탭, 검색 성공 후 결과 화면 이동, 단지 상세 패널 |
| **나의 관심집** | 거래 카드를 저장·해제하고 저장 시점의 가상/공식 모드·조회 기간 확인 |
| **3D 아파트 탐험** | 24초 반복 장면, 시네마틱·오로라·고요한 밤, 재생·정지·처음부터·타임라인 탐색 |
| **가격 착시 탐정** | 전체 거래의 변화와 같은 동·단지·면적 구간 비교. 가상 연습 예제에서 전체 +100%와 같은 구성 0% 확인 |
| **주소 블라인드 선택실험** | 이름을 가린 가격·면적·표본 카드 선택 → 이름 공개 → 선택 유지·변경 |
| **내 자금 계획** | 매매·전세·월세 요약, 기간·면적·동 필터, 예산 적합도와 금리 스트레스 계산 |

v0.5는 긴 대시보드를 여섯 화면으로 나누고 체험 프로필, 검색 패널, 매매·전세·월세 전환, 단지 상세와 관심집을 추가했습니다. 자금 계산 중에는 현재 화면을 유지합니다. 3D는 동영상 파일을 내려받는 대신 코드로 그리며 실제 지도나 특정 아파트의 복원이 아닙니다. 움직임 감소 설정에서는 정지 상태로 시작하고, 화면 밖·숨긴 탭·비활성 화면에서는 렌더링을 쉽니다.

## 내 선택의 가격

하단 **발견 → 주소 블라인드 선택실험**에서 조건 선택, 주소 공개, 최종 선택을 마친 뒤
**가격이 달라지면 내 선택도 바뀔까?**를 누릅니다. 건너뛰어도 기존 실험은 그대로 사용할 수 있습니다.
최종 선택은 A로 고정하고 다른 후보를 B로 고르면, B의 기준 가격을 0~30%까지 1%씩 낮춰볼 수 있습니다.
슬라이더는 가격 가정만 변경하며 **이 가격이면 B 선택 / A 유지 / 판단 어려움** 버튼으로 선택을 확정합니다.
조절값이나 B를 바꾸면 확정 결과가 해제되고, 지역·조회 조건을 바꾸면 실험 전체가 초기화됩니다.

원래 기준 가격, 원 단위 가정 가격, 차액, 기존 면적·표본·출처를 구분해 표시합니다.
결과는 주소 공개 전·후와 가정 가격 적용 후 선택을 비교하며, 문구 복사와 직접 텍스트 선택을 제공합니다.
실험은 페이지 메모리에만 유지됩니다. 원본 거래, 관심집, 자금계획에는 반영되지 않으며
실제 적정가·투자 추천·심리 진단·정확한 선택 전환점을 알려주는 기능이 아닙니다.

## 공식 자료 연결

[매매 API](https://www.data.go.kr/data/15126469/openapi.do)와 [전월세 API](https://www.data.go.kr/data/15126474/openapi.do) 활용신청 후 **서버 환경변수 `MOLIT_SERVICE_KEY`**를 설정하고 서버를 다시 실행합니다. Replit에서는 Secrets에 넣습니다. `.env`는 자동으로 읽지 않으며 키를 소스나 `play.html`에 넣지 않습니다.

설치 없는 파일·비공개 정적 웹앱은 가상 자료 전용입니다. 이 화면에서 공식 자료로 자동 전환하지 않습니다. 서버의 공식 조회 실패도 가상 자료로 대체하지 않습니다. 실제 발급키와 Replit 게시 환경의 외부 API 연동은 별도 확인이 필요합니다.

Python과 설치 없는 버전은 서로 다른 재현 가능한 가상 자료 생성기를 사용하므로 예시 금액이 다를 수 있습니다. **같은 거래 입력에 대한 계산·실험 결과**는 두 런타임의 비교 검사로 확인합니다.

## 숫자를 읽는 기준

- 공식 모드는 신고된 과거 계약 자료이며 현재 매물의 호가가 아닙니다.
- 가격 착시는 동일 지역·동·단지·5㎡ 구간을 비교합니다. 같은 세대의 반복 거래·공식 가격지수·상승 원인 판정이 아닙니다.
- 블라인드 후보는 과거 거래의 집계 카드이며 투자 추천이나 성향 진단이 아닙니다.
- 조건 적합도는 예산 60점 + 자기자금 40점의 공개 가정식입니다. 매매 5건 미만이면 보류합니다.
- 자금 입력은 **만원**, API·JSON 계산은 **원**입니다. 기본 월 현금흐름은 원금상환·세금을 제외합니다.

[계산식과 자료 한계](docs/DATA_SOURCES.md)를 함께 제공합니다. 자금 계산은 **지역의 매매 중앙값 기준**이며 선택한 단지의 매수 견적이 아닙니다. 닉네임·최근 검색·관심집은 해당 브라우저에만 보관하고, 금융 입력과 블라인드 선택 이력은 자동으로 영구 저장하지 않습니다. 다운로드 JSON에는 입력 가정이 포함되며 화면 공유 링크에는 포함되지 않습니다.

## 수정·빌드·검증

```bash
python3 -m unittest discover -s tests -v
python3 build_static.py
python3 build_static.py --check
```

`play.html`과 `dist/index.html`은 같은 파일로 생성됩니다. 직접 수정하지 말고 `public/`과 계산 엔진을 수정한 뒤 다시 빌드합니다. Node가 있으면 `npm run check:js`로 7개 JavaScript의 문법을 검사합니다. Python 테스트의 Node 기반 항목은 Node가 없으면 건너뜁니다. 앱 사용에 npm 설치는 필요 없습니다.

| 주요 파일 | 역할 |
| --- | --- |
| `play.html`, `build_static.py` | 설치 없는 실행본과 재현 가능한 빌더 |
| `server.py`, `analytics.py`, `insights.py` | Python API·거래 계산·두 실험 |
| `molit.py`, `demo.py`, `data/regions.json` | 공식 조회·가상 자료·지원 지역 |
| `public/local-*.js` | 설치 없는 자료·계산·실험 엔진 |
| `public/app.js`, `public/index.html`, `public/styles.css` | 검색·자금 입력·화면 구조 |
| `public/mobile.js`, `public/mobile.css` | 화면 이동·체험 프로필·검색/상세 패널·관심집·모바일 스타일 |
| `public/journey.*`, `public/labs.*` | 3D 장면과 두 실험 UI |
| `.replit`, `start.bat`, `start.sh` | Replit·로컬 서버 실행 |
| `tests/`, `.github/workflows/ci.yml` | 자동 검사와 CI |

동네렌즈 퀘스트

공개 가상 데이터 체험판
https://johnnyscalper.github.io/dongne-lens-quest-adavanced/
로그인·API 키 없이 체험합니다. 실제 시세나 매물이 아닙니다.

체험 순서
게스트 진입 → 지역 검색 → 결과 → 하단 발견 → 주소 블라인드 선택실험
→ 주소 공개 후 최종 선택 → 내 선택의 가격 → B 선택·할인 가정 → 결과 확정

설치 없이 실행: play.html을 다운로드해 브라우저로 엽니다.
Python 실행: python3 server.py --host 0.0.0.0 --port 3000
Python 3.11 이상, 추가 패키지 설치 없음. http://localhost:3000 접속.
Replit: 현재 공개 저장소를 가져온 뒤 Run.
공식 자료는 서버 환경변수 MOLIT_SERVICE_KEY 설정 후 Python 서버에서만 사용합니다.
Pages는 가상 자료 전용입니다. 키를 소스나 HTML에 넣지 마세요.

소스 수정 후: python3 build_static.py
정적 실행본: play.html / dist/index.html
main 변경 시 GitHub Actions에서 테스트·빌드 후 GitHub Pages로 배포합니다.

자세한 안내와 검수 범위: README.md / docs/REPLIT.md / docs/VALIDATION.md
